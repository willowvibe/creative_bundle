For explainer videos (business breakdowns, cost teardowns), follow `video-editor/docs/EXPLAINER_PLAYBOOK.md`
in order: research + number model → script → on-screen calcs → geography → screen plan → timing/animation →
stock and stills → voice → music/SFX → captions → hook/end screen → render, frame review, outside review.

**Why:** the owner asked on 2026-11-26 for one repeatable pattern after the tiffin teardown took nine renders
and an outside review to get right. The owner's draft order (script first, audio late) was corrected:
numbers before the script (the tiffin claim changed after the arithmetic), and the paid voice is bought only
once the script and screen plan are final, because every cue is timed from it.

**How to apply:** at the start of a new explainer, open the playbook and work through each stage's check
before moving on. Prefer free Flow stills via Claude in Chrome over PoYo, and ElevenLabs for the voice
(owner's choice, 2026-11-26). Verify every outside-review claim on frames before fixing.
