# Engine Audit — 2026-07-05

A complete read-only scan of the engine by 6 parallel auditors (CLI/pipeline, state+LLM, ffmpeg+asset_ingestion, skills, engine-core, tests+config+cross-cutting). ~130 raw findings, deduplicated and ranked below. Distinct from the historical `docs/ISSUES_BUGS.md` (#1–#51, mostly closed) — these are **new** findings, numbered `A1…`.

Severity legend: **CRITICAL** (silent data loss / silent wrong output / breaks a real path), **HIGH** (significant correctness or robustness gap), **MEDIUM**, **LOW**.

---

## CRITICAL — silent wrong output or job loss

### A1 — `asyncio.run()` inside a running event loop crashes the `ve enqueue run → ve worker` path
`SkillsPipeline.run` is sync but calls `asyncio.run(self._generate_and_mix_sfx(...))` (pipeline.py:229) and `asyncio.run(self._generate_music())` (pipeline.py:238). The worker `_handle_run` is `async` and awaited inside the worker's `asyncio.run` loop, so a loop is already running when `skills.run()` is invoked. Python raises `RuntimeError: asyncio.run() cannot be called from a running event loop` the moment the SFX or music-prompt branch fires. The sync `ve run <file>` path works (no loop); only the worker path breaks — and only with `--sfx-provider` or `--music-prompt`, which the e2e worker test deliberately omits.
**Fix:** Make `SkillsPipeline.run` async; `await` the sub-coroutines; `_handle_run` awaits `skills.run(...)`; the sync `ve run` CLI does `asyncio.run(skills_pipeline.run(...))`. Add a worker e2e test with `sfx_provider` + `music_prompt`.

### A2 — Stub fallback permanently poisons the FAL asset cache
`manager._generate_one` catches a `fal_ai` IMAGE/VIDEO failure, writes the placeholder to the FAL cache path, and calls `_save_cached`. The cache key is derived from the request (`provider="fal_ai"`), not the actual generator. Every subsequent run hits the cache and returns the stub — FAL is never retried after an outage. The pipeline silently stays on placeholders forever.
**Fix:** Don't cache fallback results (skip `_save_cached` when the result came from a fallback), or namespace the cache key by actual generating provider + a "degraded" flag with a TTL.

### A3 — Tenacity retries non-retryable 4xx (401/403/400/404)
`_RETRYABLE_EXCEPTIONS` includes every `httpx.HTTPStatusError` (manager.py:31-36). A bad API key wastes 3 attempts with exponential backoff before surfacing — slowing failure detection ~10s and risking secondary rate-limit penalties on providers that count 401s.
**Fix:** Retry only `{429, 500, 502, 503, 504}`; let 4xx (except 429) fail fast.

### A4 — `QASkill._parse_ffmpeg_regions` crashes on trailing silence/black
`zip(starts, ends, strict=True)` raises `ValueError` when `silence_start` has no matching `silence_end` — the common case for any video that ends in silence or fade-to-black. The trailing-region handler (qa.py:57-59) is dead code; the strict zip throws first. `QASkill.run` propagates an uncaught `ValueError` on most real-world videos.
**Fix:** `strict=False`, then apply the trailing-region logic. Regression test on a video ending in silence.

### A5 — Multi-logo FFmpeg filter chain is malformed (stray `]`)
`renderer.py:195`: `out_label = "vout" if is_last else f"mix{idx}]"` — the `]` makes the chain `[base][logo1]overlay=...[mix1]]` (double `]`), which FFmpeg rejects as a syntax error. Only single-logo is tested, so CI is green but any composition with ≥2 logo layers fails the render.
**Fix:** `f"mix{idx}"` (no `]`). Add a 2-logo renderer test.

### A6 — Second-pass drops the brand logo → visually inconsistent output
`second_pass.apply_edit` re-plans via `plan_segments(new_edl, preset, transcript, source_video)` with no `brand=` kwarg (second_pass.py:86). The original plan had logo layers; the new plan has none. Combined with `rebuild_after_edit` reusing cached files for unchanged segments, the rebuilt video has logo on unchanged segments and NO logo on changed segments.
**Fix:** Carry the original plan's brand (or read from `ctx`) and pass `brand=` into `plan_segments`. Brand-persistence test.

### A7 — `silence.py` uses `check=False` and silently returns empty silences on ffmpeg failure
`detect_silence` (analysis/silence.py:49-71) ignores the return code. If ffmpeg fails (missing input, no audio stream), it finds no `silence_start/end` lines and writes `{"silences": []}` as if analysis succeeded. The pipeline then proceeds with no silence removal — a silent-failure mode. No timeout either.
**Fix:** Check `result.returncode`; raise `SilenceDetectionError` carrying `stderr`. Add a timeout. Regression test for non-zero return code.

### A8 — Empty source dir → `IndexError` in transcribe/analyze/cut
`ingest()` happily returns `{"sources": []}` for an empty dir; `transcribe()` then does `ingest["sources"][0]` → `IndexError` (raw_footage.py:103,117,176). Opaque traceback instead of "no source media found."
**Fix:** Fail `ingest()` with a typed `NoSourceMediaError` when sources is empty. Regression test.

### A9 — Destructive dequeue → job silently lost on worker crash
`queue.dequeue()` `popleft()`s the message before dispatch. If the worker is SIGKILL'd/OOM-killed between dequeue and complete/fail, the message exists in none of pending/completed/failed — it is gone. No in-flight set, no ack/nack, no requeue-on-crash.
**Fix:** Maintain `_in_flight: dict[job_id, JobMessage]` populated in `dequeue`, drained by `complete`/`fail`; expose `requeue_stale()`.

### A10 — Manifest `.tmp` collision under concurrent writers → silent data loss
`manifest.save()` uses a fixed `.tmp` path per manifest (manifest.py:41-55). Two concurrent writers: A writes tmp, B truncates tmp and writes B's bytes, A's `os.replace` persists B's data, B's `os.replace` raises `FileNotFoundError`. Atomic-rename only protects against mid-write crashes, not concurrent writers. Bites the multi-worker design the queue ABC invites.
**Fix:** Unique tmp name (pid + uuid4 hex) or `flock(target)`.

### A11 — `hyperframes_cli.render_segment` returns a 0-byte / zero-duration output as success
The wrapper (hyperframes_cli.py:25-47) calls `subprocess.run(check=True, timeout=)` and returns `output` unconditionally on return code 0. The known `Composition has zero duration / __hf.duration: 0` failure (which forced the Saju/ShaadiBio ffmpeg-mix bypass) silently succeeds here and poisons downstream `amix`/`concat` with a 0-duration stream. No stderr capture, no stat, no ffprobe duration check, no retry, no fallback.
**Fix:** After run: capture stderr, stat output > 0, `ffprobe` duration > 0; on failure raise typed `RenderSegmentError` carrying stderr; offer a caller-supplied fallback (ffmpeg-mix) + one retry. Regression test for 0-byte and duration=0.

## HIGH — correctness / robustness gaps

### A12 — No subprocess timeout anywhere; hung FFmpeg/Whisper/HyperFrames wedges the worker
Every `subprocess.run` in the ffmpeg package, `silence.py`, `broll_assets._normalize_clip_duration`, and `remotion_renderer.py` uses `check=True` but no `timeout=`. A corrupted input or stalling network source hangs the dispatching handler indefinitely; in the worker path this also blocks the asyncio loop. Only `hyperframes_cli` has a 600s default.
**Fix:** Central `_run_subprocess(cmd, *, timeout=)` helper (see B2); per-call-site defaults (e.g. 600s render, 60s probe).

### A13 — Subprocess stderr is not captured; `queue.fail` only sees the return code
Most `subprocess.run(..., check=True)` calls let stderr fall through to the parent (lost in detached workers) or capture it but never add it to the exception. The user sees "Command 'ffmpeg' returned non-zero exit status 1" with no diagnostic. Bites every ffmpeg/whisper/hyperframes failure.
**Fix:** Central `_run_ffmpeg`/`_run_subprocess` that always captures stderr and re-raises with `stderr` tail appended (see B2).

### A14 — LLM config silently falls back to Ollama when a provider/key is missing
`provider_for_task` returns `(provider_name, "")` even when `provider_name` isn't in `providers` (config.py:117-145); `client_kwargs` returns `{}`; `OllamaClient` then falls back to `OLLAMA_API_KEY`. A config that says `default_provider: openai` with no `openai` provider silently routes everything to Ollama. Separately, a configured `api_key_env` that resolves to `None` falls back to `OLLAMA_API_KEY` (client.py:20-22). No warning.
**Fix:** `model_validator(mode="after")` cross-checking `default_provider`/`tasks[*].provider` against `providers`; raise/warn when a configured `api_key_env` resolves to None; drop the `OLLAMA_API_KEY` fallback when an explicit `api_key=None` was passed.

### A15 — `provider_for` returns the wrong provider's config silently
When a requested provider isn't in `config.providers`, `provider_for` falls back to the asset-type default, then to `next(iter(self.providers))` — returning a *different* provider's config (config.py:71-98). Result: `FalAIProvider(elevenlabs_config)` reads the wrong env key, producing opaque 401s. No warning that the requested provider was missing.
**Fix:** When `request.provider` is explicit, look it up directly and raise `RuntimeError("provider 'X' not in config.providers")` if missing. Don't fall through to an unrelated config. (Also: replace the `next(iter(...))` guess with a `ConfigError` requiring an explicit default per asset type.)

### A16 — Asset cache writes are non-atomic + no concurrency dedup → corrupt "cache hits"
Providers write `output_path.write_bytes(response.content)` directly (fal_ai.py:94, elevenlabs_*.py, openai_tts.py:76), then meta is written separately. A crash mid-write leaves a truncated media file with a valid meta → next run returns corrupt media as a hit. Concurrent `_resolve_one` for the same cache key both write to `media_path` and interleave (manager.py:196-237).
**Fix:** Write to `.tmp` then `os.replace` for both media and meta. Add an in-flight `dict[str, asyncio.Task]` keyed by `cache_key` so the second request awaits the first.

### A17 — FAL video poll timeout (120s) too short; Luma/Wan often exceed it
`POLL_MAX_ATTEMPTS=60 × POLL_INTERVAL_SECONDS=2.0 = 120s` cap (fal_ai.py:24-25,147-173). On timeout, the stub fallback kicks in (→ A2 poisons cache). No config knob.
**Fix:** Make poll budget configurable via `provider_options.poll_max_attempts`; default ~600s for VIDEO, 120s for IMAGE.

### A18 — TTS/music/SFX providers save error-JSON/HTML bodies as `.mp3`
All audio providers do `raise_for_status(); write_bytes(response.content); probe_media(...)` (elevenlabs_music.py:80-87, elevenlabs_sfx.py, elevenlabs_tts.py:78-89, openai_tts.py:72-79). A 200-OK error envelope is saved as audio, then `probe_media` raises `CalledProcessError` (not retryable, not covered by fallback) — opaque ffmpeg error, not the provider's message.
**Fix:** Check `content-type` starts with `audio/` (or magic-byte sniff) before writing; on mismatch raise `ProviderError` carrying the first 256 bytes.

### A19 — `LLMConfig.load`/`AssetProviderConfig.load` silently ignore unknown keys; 4 of 6 `config.yaml` sections are no-ops
Pydantic v2 ignores extra fields by default. `transcription:`, `audio:`, `render:`, `paths:` blocks in `config.yaml` are never read (whisperx_wrapper hardcodes `small`/`en`/`cpu`; QASkill uses brand/CLI flag; RenderCache takes a path arg). A user editing these believes they are configuring the engine; nothing changes. Same class as the Session S `llm:` no-op.
**Fix:** `model_config = ConfigDict(extra="forbid")` on `LLMConfig`, `ProviderConfig`, `AssetProviderConfig`, `TaskRouting`. Either wire the dead sections or delete them and document the CLI flags as the only knobs. Emit a startup warning for unknown top-level keys.

### A20 — No retry / DLQ / backoff in the job queue
`queue.fail()` just appends a reason; no `attempt`/`max_attempts`, no requeue, no DLQ, no exponential backoff (queue.py:34-80). A transient FAL/ElevenLabs/Ollama blip permanently fails the job. Router-side retry only covers the LLM HTTP call.
**Fix:** Add `attempt`/`max_attempts` to `JobMessage`, a `requeue(message)` method, a DLQ list, and backoff. Document the contract in the ABC.

### A21 — Audio-pop boundary check measures the prev-tail, not the boundary
`segment_check._measure_peak_rms_at_boundary` (segment_check.py:108-120): output `-t 0.1` limits the filter output, but the concat is `0.1s(prev_tail) + entire(curr)`, so only prev-tail reaches `astats`. The first 0.1s of `curr` — where the boundary transient lives — is never measured. The docstring claims a "0.2s window centered on the boundary"; the impl doesn't match. Existing test passes only because the square wave is loud throughout.
**Fix:** Trim `curr` to its first 0.1s with an input-level `-t 0.1` before `-i curr_path`; drop the output `-t`. Add a test with silent prev and a transient at `curr`'s t=0.

### A22 — Music + Export skip the broll stage; QA prefers it → three skills disagree on "the final video"
`MusicSkill._find_input_video` and `ExportSkill._find_input_video` candidate lists omit `broll/with_broll.mp4`; `QASkill._default_video_path` prefers it. If broll runs after captions, music mixes onto the captions video, export ships the captions video, and QA checks the broll video.
**Fix:** Add `broll/with_broll.mp4` to both skills' candidate lists (above captions). Test with a broll artifact present.

### A23 — No schema validation on LLM-returned scene plans / edit plans
`Scene.type: str` and `Scene.duration_seconds: float` accept anything (scene_plan.py:11-19); `Cut.start`/`Cut.end` are unconstrained (edit_plan.py:10-15). An LLM hallucination (`type: "explosion"`, `duration: -5`, `start=10, end=5`, duplicate IDs, out-of-bounds cuts) passes validation and silently corrupts the timeline.
**Fix:** `Literal[...]` for `type`; `Field(gt=0)` for durations; model validators for unique IDs and `start < end`; a post-LLM repair pass that sorts/dedupes/clips-to-duration/merges-overlaps with a warning.

### A24 — `scene_planner` raises on first LLM parse failure; no retry, no fallback
Unlike `raw_planner.plan_raw_edit` (which falls back to a deterministic planner), `build_scene_plan` raises `RuntimeError` immediately on `JSONDecodeError` or empty scenes (scene_planner.py:86-95). A single bad LLM response aborts the job.
**Fix:** Configurable retry (default 2) with a re-prompt including the parse error, then raise. Consider a deterministic fallback. Converge both planners on a shared retry+fallback policy.

### A25 — Multi-tenant path traversal in `brief`/`audio`/`align` worker handlers
`_handle_brief` reads `payload["from_md"]` (any path), `_handle_audio` reads `source`/`voiceover`, `_handle_align` reads `audio` — none validate the path is within an allowed root (main.py:1516,1479,1441). For the documented tenant-scoped worker, tenant A can read tenant B's files into their own work_dir. Brand-resolver fixed this class for brand-doc paths; payload paths are unfixed.
**Fix:** `_safe_path(payload_key, allowed_roots)` helper; reject otherwise.

### A26 — Cache key for non-existent source files collapses to `"missing"`
`render_cache._file_hash` returns `"missing"` for any non-existent source (render_cache.py:45). Two distinct missing paths with the same (operation,start,end,params) share a key — a `get` against a stale key returns an unrelated cached render.
**Fix:** Include `str(source_path)` in the hash when missing, or raise on missing source.

## MEDIUM — structure / robustness

- **A27 — No per-stage checkpoint/resume in `SkillsPipeline.run`.** Linear try-less body; a mid-pipeline failure (e.g. graphics after rough_cut) leaves partial state, no resume, no cleanup. `mix_sfx_into_video` can leave a half-written `with_broll_sfx.mp4` that MusicSkill picks up. **Fix:** per-stage try/except + `.pipeline_state.json` markers + `.tmp`-suffix partial outputs.
- **A28 — `enqueue` payloads are untyped.** Per-command required keys enforced only via mid-handler `KeyError`/`ValueError`; a typo enqueues successfully and fails opaquely. **Fix:** Pydantic `Payload` per command validated at `enqueue` (also the natural hook for the planned validation gate).
- **A29 — Worker loop has no supervision.** No try/except around `dequeue`/`_dispatch_message`; `queue.fail()` is itself unprotected (a failing `fail` kills the loop, contradicting the docstring). No backoff, no dead-letter, no graceful SIGTERM. **Fix:** per-iteration `try/except` + `continue` + backoff; wrap `fail`/`complete` in their own try/except; have `_dispatch_message` return a status literal instead of the racy before/after counter dance.
- **A30 — No observability.** structlog is imported ~30 modules but never configured in production (only in `conftest.py`). No metrics, no per-job log file, no tracing. Failed jobs leave only stderr. **Fix:** `ve` startup hook configuring a JSON structlog renderer keyed by `job_id`/`stage`, writing to `<work_root>/<job_id>/logs/worker.log`; emit `job_started/completed/failed` with timings.
- **A31 — No provider health check / circuit breaker.** Tenacity retries per request, but no manager-level tracking. If FAL is down for an hour, every batch still tries FAL 3×. **Fix:** circuit breaker (open after N consecutive failures in a window) → skip to stub.
- **A32 — All-or-nothing batch; partial success discarded.** `resolve` raises if any request fails; 19 successful downloads are discarded on 1 failure (manager.py:225-229). **Fix:** `partial_results` mode returning successes + failure list.
- **A33 — Provider instance per-request; no connection reuse.** Fresh `httpx.AsyncClient` per request → 20 TLS handshakes for a 20-request batch (manager.py:95-124). **Fix:** cache provider instances on the manager by `(name, config_hash)`; close once at end of `resolve`.
- **A34 — Unbounded per-provider concurrency.** `asyncio.gather` over N requests with no semaphore → 429 burst on 20-scene reels. **Fix:** `asyncio.Semaphore(N)` per provider, configurable via `provider_options.max_concurrency`.
- **A35 — `RenderCache` unbounded + concurrent `.tmp` race.** No eviction/size cap/TTL (render_cache.py:57-97); same-key concurrent `put`s collide on the shared `.tmp` path (render_cache.py:88-95). **Fix:** `max_bytes`/`max_entries` + mtime sweep; unique tmp name per call.
- **A36 — Whisper model reloaded on every call.** `transcribe_audio` calls `_load_model` per invocation (whisper_local.py:41-47) — multi-file jobs pay the load cost every time. **Fix:** module-level `(model_size, device)` cache guarded by a lock.
- **A37 — Second-pass bypasses the per-segment QA hook.** `rebuild_after_edit` has its own loop and never calls `check_segment_boundary` even when `run_qa_per_segment=True` (second_pass/renderer.py:37-99). **Fix:** route through `_render_all_from_inputs` or invoke `check_segment_boundary` in the loop.
- **A38 — `JobContext` performs `mkdir` in the constructor.** Defaults `/work`/`/output` raise `PermissionError` on dev machines (job.py:16-31, store.py). `ensure_dirs()` exists separately; the constructor's mkdir is redundant + a footgun. **Fix:** drop mkdir from `ArtifactStore.__init__`; require explicit `ensure_dirs()`.
- **A39 — Atomicity is inconsistent across the state package.** `JobManifest.save` is atomic; `ArtifactStore.write_json` and `ProjectBrief` writes are not (store.py:64-68). A ctrl-C mid-write leaves corrupt JSON; `read_json` raises `JSONDecodeError` with no recovery. **Fix:** extract `_atomic_write_json` and route all JSON writes through it.
- **A40 — `drawtext_captions` escaping is incomplete.** Only `\` and `'` are escaped (captions.py:14-16); `:` `,` `%` `{}` break the filter ("Time: 12:30", "100% done"). **Fix:** use `text_file=` (temp file per caption) or escape `:``,`%`.
- **A41 — `cut_segment` with `-c copy` produces broken segments on non-keyframe boundaries.** First frames up to the next keyframe are reference-less → gray/frozen glitches (cuts.py:22-33); `concat_segments` propagates. **Fix:** document `cut_segment` as "fast & lossless, may glitch"; default callers to `assemble_with_filter_complex`.
- **A42 — `concat_segments`/`burn_subtitles` don't escape paths.** Paths with `'` break the concat demuxer (cuts.py:54-57); `subtitles=` doesn't escape `:`/`'`/`\` (captions.py:170). **Fix:** escape `'` as `'\''`; apply `subtitles` filter escaping or write SRT to a safe temp path.
- **A43 — `MediaInfo.duration` returns `0.0` silently on missing duration.** Downstream `amix duration=first` against a 0-duration `[0:a]` produces a 0-length output (probe.py:31-38). **Fix:** raise `MediaInfoError` when duration missing; callers assert > 0.
- **A44 — LLM router retry undercounts attempts + no backoff.** `_record_attempt` runs once per `generate()`, not per HTTP attempt (router.py:150-160); budget charges prompt tokens once. No `asyncio.sleep` between retries; 429/5xx hammered in a tight loop; no `Retry-After`; retryable vs terminal not distinguished (router.py:225-282). **Fix:** record per actual invocation; exponential backoff + jitter + Retry-After; classify status codes.
- **A45 — Router guardrails are approximations with no reset boundary.** `_estimate_cost_usd` hardcodes 4 Ollama model rates; non-Ollama silently defaults to 2.0/1M (router.py:102-112). `_attempts`/`_consecutive_failures`/`_circuit_open`/`_tokens_used`/`_cost` accumulate across jobs if a router is reused (router.py:71-76). **Fix:** `cost_per_million_tokens` on `ProviderConfig`; `reset()` method + documented one-per-job contract.
- **A46 — `_sorted_params` doesn't recurse into lists of dicts.** `data_viz` chart configs with reordered keys hash differently → cache miss every time (models.py:57-60). **Fix:** recurse into lists.
- **A47 — QA `audio_not_silent`/`no_black_frames` produce false positives for deliberate quiet/fades.** A 2s meditation intro or a fade-to-black fails the report (qa.py:224-244). **Fix:** configurable thresholds / downgrade to warnings.
- **A48 — `mux_voiceover` `-shortest` silently truncates the video when VO is shorter.** A 30s VO on a 2-min video drops the second half (voiceover.py:78). **Fix:** probe both, warn on mismatch, pad with silence or require `--truncate`.
- **A49 — `fal_ai._extract_download_url` raises `AttributeError` on `images: ["https://..."]`.** Assumes each entry is a dict (fal_ai.py:182-185); a list-of-strings is a valid schema variant → bubbles up → A2 poisons cache. **Fix:** `first = images[0]; return str(first["url"]) if isinstance(first, dict) else str(first)`.
- **A50 — Rough-cut/second-pass write the EDL before `render` succeeds.** A render failure leaves the on-disk EDL as the new one; retry diffs against the wrong state (rough_cut.py:394-407, second_pass.py:74-75). **Fix:** write EDL only after render succeeds, or `.tmp`+rename.
- **A51 — `RoughCut` is not idempotent / no checkpoint resume.** Always re-copies source, re-makes proxy, re-extracts audio, re-runs WhisperX even if `transcript.json` exists. **Fix:** skip if manifest + outputs exist (`force=False` default).

## LOW — doc drift, test gaps, minor

- **A52 — README doc drift.** Architecture lists `apps/editor`, `apps/renderer`, `packages/remotion-types` — none exist in the repo. Project Layout tree omits `apps/transcribe`/`eval`/`assets`. **Fix:** reconcile README with actual dirs.
- **A53 — CLI_USAGE doc drift.** Per-command table omits `sfx_mix`; `ve dequeue`, `ve queue-size`, `ve probe`, `ve render`, `ve plan-script`, `ve sfx-mix` are undocumented. README "Legacy" mentions `ve broll` (no such CLI command). **Fix:** add the rows/section.
- **A54 — Test coverage gaps (high-leverage).** Untested: `llm/router.py` retry/fallback/circuit/budget (only construction + `select`), `llm/client.py` (no test file), `analysis/pace.py`, `ffmpeg/normalize.py`, `ffmpeg/proxy.py`, `tools/ffmpeg_wrapper.py`, `apps/cli/remotion_renderer.py`, multi-logo rendering, duplicate logo sources, brand-persistence through second-pass, audio-pop boundary window (silent prev + transient at curr t=0), concurrent manifest save, `ArtifactStore.write_json` interruption, `JobContext` default-roots failure. **Fix:** add focused tests per module.
- **A55 — Aggressive mocking in worker tests.** `fake_handlers` replaces `_HANDLERS` entirely; 8 of 10 dispatch tests never exercise a real handler's contract. Only `TestRealPipelineRunsThroughEnqueueWorker` (Session Q) uses real handlers, and only for `run`/`audio`. **Fix:** one real-handler test per command with stub providers.
- **A56 — Tests assume ffmpeg on PATH.** `tmp_media` fixture and ~10 test files shell out with no `shutil.which` guard → `FileNotFoundError` instead of `pytest.skip`. **Fix:** `_require_ffmpeg()` session guard.
- **A57 — Some tests assert only exit code 0, not the on-disk artifact.** `test_music_generate_with_stub_provider`/`test_align_with_stub_provider` don't assert the output file exists/shape — a stub producing nothing still passes. **Fix:** assert non-empty / parseable output.
- **A58 — Registry eager-imports matplotlib.** `registry.py:7-20` unconditionally imports `MatplotlibDataVizProvider`; a missing matplotlib breaks all providers including TTS. **Fix:** lazy-import per provider.
- **A59 — Stub image provider uses a 2M-iteration Python pixel loop.** ~5-10s per image (visual/stub.py:35-41). **Fix:** numpy broadcasting + `Image.fromarray`.
- **A60 — `register_provider` silently overwrites duplicate names.** Last-registered wins, no warning (registry.py:49-51). **Fix:** warn or raise.
- **A61 — `ArtifactStore.output()` uses fragile `str.replace("/work/","/output/")`.** No-op when work_dir doesn't match the convention; currently unused but exported (store.py:36-40). **Fix:** delete or reimplement against `ctx.output_dir`.
- **A62 — Two divergent ffmpeg-region parsers.** `rough_cut._silence_regions` (legacy, silent drop) and `qa._parse_ffmpeg_regions` (newer, strict-zip crash A4) implement the same idea differently; neither tested against unpaired events. **Fix:** consolidate into one shared `video_editor_ffmpeg` helper with a tested parser.
- **A63 — `DEFAULT_MUSIC_PATHS` / `presets_dir` are CWD-relative.** A worker launched from a non-repo cwd silently fails to auto-discover music/presets (pipeline.py:27-31, graphics.py:63). **Fix:** resolve against repo root (or `ctx.work_dir`).
- **A64 — `--force` silently ignored on the v2 file-source path.** No warning, unlike `--broll-provider` (main.py:714,767). **Fix:** echo a one-line no-op warning.
- **A65 — `SegmentEdit.regenerate_graphics` is unused.** Model declares it; `apply_segment_edit`/`apply_edit` never read it (second_pass/models.py:14). **Fix:** honor it or remove.
- **A66 — `chat(stream=True)` returns `response.json()` — hangs/raises on a streaming response.** Latent (router always uses `stream=False`) but the public API lies (client.py:38-57). **Fix:** implement streaming or remove the param.
- **A67 — `inspect.iscoroutine` misses Tasks/Futures.** `_dispatch_message` awaits only coroutines, not futures (main.py:1177). Latent. **Fix:** `inspect.isawaitable`.
- **A68 — `_get_client` not safe under concurrent first-use.** Two coroutines can leak an `httpx.AsyncClient` (client.py:26-36). Latent under the single-threaded loop. **Fix:** `asyncio.Lock` or eager construction.
- **A69 — `apps/eval` and `apps/assets` are docstring-only stubs.** Live QA code is in `skills/qa/`; live asset code in `packages/asset_ingestion/`. **Fix:** delete the stubs or fold the live code in.
- **A70 — `_RETRYABLE_EXCEPTIONS` includes `CalledProcessError`-class failures from `probe_media`.** Combined with A18, a bad-audio probe retries 3× before failing. **Fix:** scope retry to transport/5xx/429.

## Architecture changes for robustness (cross-cutting)

These are the structural investments that fix whole classes of the above findings at once.

### B1 — Validation gate (the planned guardrails)
Typed Pydantic `Payload` model per worker command, validated at `enqueue` (fail-fast with field-level errors before the job is queued). Pre-flight in `SkillsPipeline.run` (source exists, transcript exists if provided, work_dir writable). This is the natural hook for the script/on-screen-text validator already specced. Closes **A28** and gives the guardrails a single enforcement point.

### B2 — One central subprocess helper
A `_run_subprocess(cmd, *, timeout, cwd=None, capture=True)` (in `packages/ffmpeg`) that always captures stderr, enforces a timeout, and re-raises a typed `SubprocessError(cmd, returncode, stderr_tail, stage, job_id)` on failure. Migrate every ffmpeg/whisper/hyperframes/pnpm callsite to it. Closes **A12, A13** and the per-audit "stderr not surfaced" findings in one place.

### B3 — Queue robustness
`_in_flight` tracking + ack/nack + `requeue_stale()` + `attempt`/`max_attempts` + exponential backoff + a DLQ; a `RetryJobQueue` wrapper. Document the contract in the `JobQueue` ABC so a persistent backend (Redis/PG) implements the same semantics. Closes **A9, A20, A29**.

### B4 — Stage-level idempotency + atomic writes
Generalize the manifest's `stages.<name>.outputs` markers (already used for transcription in Session W) to every `SkillsPipeline` stage and every skill: skip on re-run unless `--force`. Per-file checkpoint in `ingest`. Extract `_atomic_write_json` and route all JSON writes (manifest, store, brief, plan, report) through it. Closes **A10, A27, A35, A39, A50, A51**.

### B5 — Render fallback
`hyperframes_cli.render_segment` detects 0-byte / zero-duration outputs, retries once, then invokes a caller-supplied fallback (the proven ffmpeg-mix path). Typed `RenderSegmentError`. Closes **A11** and removes the single-point-of-failure that forced hand-rolled ffmpeg-mix on Saju/ShaadiBio.

### B6 — Config strictness
`extra="forbid"` on all config models; cross-validate `default_provider`/`tasks[*].provider` against `providers`; warn on unknown top-level keys. Wire or delete the dead `transcription:`/`audio:`/`render:`/`paths:` sections. Closes **A14, A15, A19**.

### B7 — Provider/asset robustness
Per-provider concurrency semaphore; provider instance reuse; content-type validation on audio bytes; retry only `{429,5xx}`; cache key includes actual generating provider; don't cache stub fallbacks; in-flight dedup; provider health/circuit breaker; partial-results mode. Closes **A2, A3, A16, A17, A18, A31, A32, A33, A34, A49**.

### B8 — LLM router hardening
Retry only retryable status; exponential backoff + jitter + `Retry-After`; per-attempt budget/token accounting; `cost_per_million_tokens` on `ProviderConfig` (not hardcoded); `reset()` boundary + one-per-job contract. Closes **A44, A45**.

### B9 — Schema validation for LLM outputs
`Literal` scene types; `Field(gt=0)` durations; unique-ID + `start<end` validators; a post-LLM repair pass (sort/dedupe/clip/merge-overlaps) with warnings. Retry on parse failure with an error-including re-prompt; converge both planners on a shared policy. Closes **A23, A24**.

### B10 — Observability
`ve` startup hook configuring a JSON structlog renderer keyed by `job_id`/`stage`, writing per-job `logs/worker.log`; emit `job_started/completed/failed` with stage timings. Closes **A30** and turns "Command returned non-zero" failures into triageable events (combined with B2).

### B11 — Inter-skill contract + shared ffmpeg helpers
A manifest-level "current video" pointer (or a shared handoff schema with version fields) so adding a stage doesn't require editing every downstream skill's candidate list. Consolidate the two ffmpeg-region parsers into one tested helper. Closes **A22, A62** and the implicit-coupling structural risk.

### B12 — Multi-tenant path safety
`_safe_path(payload_key, allowed_roots)` used by `brief`/`audio`/`align`/any handler that reads a payload-supplied path. Closes **A25**.

## Suggested fix order (priority)

1. **CRITICAL silent-wrong-output bugs** — A1 (worker run crash), A4 (QA crash), A5 (multi-logo), A6 (logo drop), A7 (silence silent-fail), A11 (zero-duration render), A2/A3 (cache poison + 4xx retry). These break real paths or silently ship wrong output today.
2. **B2 subprocess helper + B5 render fallback + B10 observability** — the foundation that makes every later fix debuggable; small, mechanical, high leverage.
3. **B6 config strictness** — stops the "tuning knobs that do nothing" class.
4. **B3 queue robustness + B4 idempotency/atomic writes** — stops job loss and re-run waste.
5. **B7 provider/asset robustness + B8 LLM router** — stops the silent-fallback and retry-pathology classes.
6. **B9 schema validation + B1 validation gate** — the guardrails (B1 is the specced validator; pause the new-video build until the gate lands).
7. **HIGH correctness gaps** — A21 (boundary check), A22 (broll handoff), A23/A24 (planner validation/retry), A25 (path traversal), A26 (cache key).
8. **MEDIUM/LOW** — doc drift (A52/A53), test gaps (A54-A57), minor bugs.
