# YouTube Publish Implementation Plan

> **Moved 2026-11-03.** This work now lives in its own repo, `/mnt/data2/git_repos/creative_repos/social-engine` (shared publishing core + YouTube first; Instagram/Facebook/TikTok later). Current versions: `social-engine/docs/specs/2026-11-03-social-engine-youtube-design.md` and `social-engine/.plan/youtube.md`. Kept here for history; do not build from this copy.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. In this repo each step is sent to the Cheap Agent `delegate` tool (`plan: docs/archive/plans/2026-11-03-youtube-publish.md`, `steps: "<id>"`).

**Goal:** Publish and manage videos on the owner's YouTube channels from one `youtube.yaml` manifest per video, through an API lane and a YouTube Studio browser lane.

**Architecture:** New workspace package `packages/youtube` (import name `video_editor_youtube`) holds the manifest, auth, API client and operations. A Node driver at `packages/youtube/studio/` attaches over CDP to a per-channel Chrome profile and walks Studio screens, stopping before every final Publish/Save click; Python calls it through `run_subprocess` with JSON in/out. `ve yt …` (Typer sub-app) and MCP tools are thin surfaces over the same operations. Spec: `docs/archive/specs/2026-11-03-youtube-publish-design.md`.

**Tech Stack:** Python 3.12, Typer, pydantic v2, PyYAML, google-api-python-client, google-auth-oauthlib; Node ≥22, playwright-core 1.63.0 (same version flow-mcp uses), `node --test`.

**Global Constraints** (every step includes these)

- Package layout copies `packages/fablecut_bridge`: hatchling, `src/video_editor_youtube/`, pinned deps; register in root `pyproject.toml` `[tool.uv.workspace] members`, `[tool.uv.sources]`, `tool.mypy.mypy_path`, `tool.importlinter.root_packages`.
- Direct `subprocess` is ruff-banned; use `run_subprocess` from the ffmpeg package (`ffmpeg/run.py`) with an explicit timeout.
- All state lives under `~/.config/video-editor/youtube/`, overridable by env `VE_YOUTUBE_HOME` (tests always set it to a tmp dir). Token and profile files are written with mode 0600; nothing under the repo, nothing in `.env`.
- Default privacy is `private`. No operation deletes a video, caption track or playlist.
- Every action that makes something visible (upload, publish/schedule click, privacy change) requires an explicit confirmation flag (`--yes` on the CLI after a printed summary, `confirm: true` in MCP, a second `confirm` call for Studio).
- Tests never touch the network or a real browser: the API is faked behind `YouTubeApi`, Studio steps run against local HTML fixtures.
- Run one test file at a time: `uv run pytest tests/<file>.py -q`. Lint touched files: `uv run ruff check <paths>` and `uv run mypy packages/youtube`.
- Commit after each step with a conventional message ending in `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

**Shared interfaces** (names every step uses)

- `video_editor_youtube.paths`: `youtube_home() -> Path`, `token_path(channel) -> Path`, `profile_path(channel) -> Path`, `chrome_profile_dir(channel) -> Path`, `client_secret_path() -> Path`.
- `video_editor_youtube.manifest`: `class Manifest(BaseModel)` (fields exactly as the spec's YAML: `channel, video, kind, title, description, chapters, tags, category, default_language, default_audio_language, made_for_kids, synthetic_media, privacy, publish_at, thumbnail, captions: dict[str,str], localizations: dict[str, Localization], playlists: list[str], dubs: dict[str,str], video_id, uploaded_via, uploaded_at`); `load_manifest(path) -> LoadedManifest` (manifest + base dir, paths resolved); `validate(loaded) -> list[Issue]`; `render_description(loaded) -> str`; `write_back(path, **fields) -> None` (rewrites only the write-back keys, preserves comments/order of the rest).
- `video_editor_youtube.profiles`: `class ChannelProfile(BaseModel)` (`name, channel_id: str|None, cdp_port: int, api_audited: bool=False`); `load_profile(name) -> ChannelProfile`; `save_profile(p) -> None`.
- `video_editor_youtube.errors`: `class YouTubeError(Exception)` with `code: str` and `next_step: str`; subclasses `QuotaExceeded, UploadLimitExceeded, PrivateLocked, AuthExpired, WrongChannel, ThumbnailNotAllowed, StudioNeedsUser, StudioUnexpectedScreen`.
- `video_editor_youtube.api`: `class YouTubeApi(Protocol)` with `insert_video, update_video, get_video, set_thumbnail, list_captions, insert_caption, update_caption, list_playlists, insert_playlist, list_playlist_items, insert_playlist_item, list_my_videos, my_channel_id, analytics_report`; `GoogleYouTubeApi(credentials)` implements it.
- `video_editor_youtube.ops`: `upload(path, api, *, confirm) -> OpResult`, `update(path, api, *, confirm) -> OpResult`, `sync_captions(path, api) -> OpResult`, `sync_localizations(path, api) -> OpResult`, `sync_playlists(path, api) -> OpResult`, `list_videos(api, limit) -> list[VideoSummary]`, `stats(api, video_id, days) -> VideoStats`. `OpResult` = `{action: str, video_id: str|None, changed: list[str], warnings: list[str]}`.
- `video_editor_youtube.studio`: `studio_call(command: str, payload: dict, *, timeout: int) -> StudioResult` where `StudioResult.status ∈ {"done","ready_to_confirm","needs_user","error"}` plus `summary, video_id, screenshot, message`.
