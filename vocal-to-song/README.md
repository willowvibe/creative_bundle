# vocal-to-song

A Claude Code skill that turns a raw vocal recording into a finished devotional song (tuning, tanpura and
beat bed, arrangement, mix and master), and devotional chant ×N tracks from a single voice note
(`scripts/chant/`). See `SKILL.md`.

Split out of `video-editor` on 2026-11-11 with its history. Installed as a personal skill through the
symlink `~/.claude/skills/vocal-to-song -> /mnt/data2/git_repos/creative_repos/vocal-to-song`.
