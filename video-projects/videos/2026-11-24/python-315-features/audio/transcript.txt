I tested every feature in this video on the real release, so you will see actual output  not slides.  Here are 6 features you will actually use.  First, let's install it.  If you use UV, it is one command.  UV Python install 3.15.  A few seconds later, you have Python 3.15.2.  No installer, no admin rights and your old versions stay untouched.  If UV is new to you, my next video covers it from scratch.  Feature one, lazy imports.  Here is the problem.  This little command line, tool imports eight modules at the top.  But when you just ask for the version, it uses only one of them.  Python still loads all eight, every single run.  In 3.15, you put the new lazy keyword in front of the import.  The module is only loaded the first time you actually use it.  Same code, same imports at the top of the file.  I timed both versions, 30 runs each.  The normal imports took 355 milliseconds to start.  The lazy version took 87, that is four times faster just by adding one word.  This is huge for command line tools and big applications.  Feature two, frozen deck, a new built-in type.  It is a dictionary that cannot be changed.  Why would you want that?  Because it is hashable.  So you can use a whole settings dictionary as a key  in another dictionary or in a cache.  Here I look up the cached connection with a new frozen deck  that has the same settings.  And it finds it even with the keys in a different order.  You can still make a modified copy with the pipe operator.  But if you try to change it in place,  Python stops you with a type error.  Perfect for configuration that should never change by accident.  Feature three, Sentinel.  You have probably written this pattern.  You need a default value.  That means nothing was passed and none will not work  because none might be a real value.  Most people create a private object and compare against it.  Now there's a built-in for it.  Missing equals sentinel with a name.  Call get setting with no default  and the function knows nothing was passed.  Pass none and it treats none as a real value.  And when you print it, you see a clear name,  not some random object address.  Feature four, unpacking in comprehensions.  Say you have a list of lists and you want one flat list.  In 3.15, you can write star batch for batch in batches.  It just works.  The same idea works for dictionaries with double star  to merge them.  Run the same file on Python 3.14  and you get a syntax error.  On 3.15, you get the flat list and the merge dictionary.  Feature five is quiet, but it fixes a classic bug.  When you open a file without saying which encoding to use,  Python used to pick your system's setting.  On Windows, that was often an old code page.  So writing text like cafe or an emoji  or Telugu could crash or save garbage.  From 3.15, the default is UTF-8 everywhere.  Here I open a file with no encoding argument  and the encoding is UTF-8.  Your scripts now behave the same on every machine.  Feature six is my favorite.  Python 3.15 ships a new profiling package  with a sampling profiler called tachyon.  Here is a script that builds a report  and it feels slow instead of guessing,  run python-mprofiling.sampling, run, and your script.  It samples your program a thousand times a second  with very low overhead.  The report shows slow total was on the stack  72% of the time.  And the culprit is JSON,  encoding and decoding every row for no reason.  Add dash dash flame graph  and you get an interactive flame graph in your browser.  One line fix, add the price directly.
