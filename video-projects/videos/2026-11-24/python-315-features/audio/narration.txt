Python three fifteen is out. It shipped in October, and the latest version, three fifteen point two, is already here. And this release is not just speed tweaks. There are new keywords, new built-in types, and a brand new profiler. I tested every feature in this video on the real release, so you will see actual output, not slides. Here are six features you will actually use.

First, let's install it. If you use uv, it is one command. uv python install three fifteen. A few seconds later, you have Python three fifteen point two. No installer, no admin rights, and your old versions stay untouched. If uv is new to you, my next video covers it from scratch.

Feature one: lazy imports. Here is the problem. This little command line tool imports eight modules at the top, but when you just ask for the version, it uses only one of them. Python still loads all eight, every single run. In three fifteen, you put the new lazy keyword in front of the import. The module is only loaded the first time you actually use it. Same code, same imports at the top of the file. I timed both versions, thirty runs each. The normal imports took three hundred and fifty five milliseconds to start. The lazy version took eighty seven. That is four times faster, just by adding one word. This is huge for command line tools and big applications.

Feature two: frozendict, a new built-in type. It is a dictionary that cannot be changed. Why would you want that? Because it is hashable. So you can use a whole settings dictionary as a key in another dictionary, or in a cache. Here, I look up the cached connection with a new frozendict that has the same settings, and it finds it, even with the keys in a different order. You can still make a modified copy with the pipe operator. But if you try to change it in place, Python stops you with a TypeError. Perfect for configuration that should never change by accident.

Feature three: sentinel. You have probably written this pattern. You need a default value that means nothing was passed, and None will not work, because None might be a real value. Most people create a private object and compare against it. Now there is a built-in for it. MISSING equals sentinel, with a name. Call get setting with no default, and the function knows nothing was passed. Pass None, and it treats None as a real value. And when you print it, you see a clear name, not some random object address.

Feature four: unpacking in comprehensions. Say you have a list of lists, and you want one flat list. In three fifteen you can write star batch, for batch in batches. It just works. The same idea works for dictionaries, with double star, to merge them. Run the same file on Python three fourteen, and you get a syntax error. On three fifteen, you get the flat list and the merged dictionary.

Feature five is quiet, but it fixes a classic bug. When you open a file without saying which encoding to use, Python used to pick your system's setting. On Windows, that was often an old code page, so writing text like café, or an emoji, or Telugu, could crash or save garbage. From three fifteen, the default is UTF-8 everywhere. Here, I open a file with no encoding argument, and the encoding is UTF-8. Your scripts now behave the same on every machine.

Feature six is my favourite. Python three fifteen ships a new profiling package with a sampling profiler called Tachyon. Here is a script that builds a report, and it feels slow. Instead of guessing, run python dash m profiling dot sampling, run, and your script. It samples your program a thousand times a second, with very low overhead. The report shows slow total was on the stack seventy two percent of the time. And the culprit is json, encoding and decoding every row for no reason. Add dash dash flamegraph, and you get an interactive flame graph in your browser. One line fix, add the price directly. The script went from zero point seven nine seconds to zero point two four. More than three times faster, found in seconds.

So that is Python three fifteen. Lazy imports, frozendict, sentinel, unpacking in comprehensions, UTF-8 by default, and the Tachyon profiler.
