I asked Claude: how far is my Goa trip, in miles? It searched my own notes, found six hundred and fifty kilometres, and called a converter to get about four hundred and four miles. Both of those tools are tiny Python functions I wrote. The thing that connects them to the AI is called MCP. In the next few minutes, we build this server from scratch, test it, connect it, and make sure it cannot leak your secrets.

MCP, the Model Context Protocol, is an open standard for connecting AI apps to tools and data. Think of it like a USB-C port for AI. You write a server once, and Claude, VS Code, Cursor and other apps can all use it. Your server offers tools, and the AI decides when to call them.

We will use FastMCP, the most popular Python framework for MCP. It is on version four now. Following my uv video, this is a single file script. uv add dash dash script server dot py fastmcp. That writes the dependency into the file, so there is no virtual environment to manage.

Here is the whole server. We create a FastMCP app called My Notes. Then each tool is just a Python function with the at mcp dot tool decorator. This one searches my notes folder for a word and returns the matching lines. The important part: the type hints and the docstring are not decoration here. FastMCP turns them into the description the AI reads, so a clear docstring is how the AI knows when to use your tool.

The second tool converts kilometres to miles, kilograms to pounds, and Celsius to Fahrenheit. And at the bottom, mcp dot run starts the server. That is it. About thirty five lines, two tools.

Before connecting an AI, test it yourself. fastmcp list shows both tools, with the inputs the AI will see. fastmcp call runs one directly. Search for goa, and it finds my trip plan. Convert six hundred and fifty kilometres, and you get four hundred and three point nine miles. If this works, the AI side will work too.

Now let's connect it. fastmcp install has ready commands for Claude Desktop, Claude Code, Cursor and more, or mcp json prints the config to paste into any app. I gave this config to Claude Code and asked my question. Watch the tool calls. It searched for Goa, then searched again for kilometres, then called convert units. Three calls, all decided by the AI, all running my Python on my machine.

Now the part most tutorials skip. Here is a read note tool that takes a file name. Looks harmless. But ask it for dot dot slash dot env, and it walks out of the notes folder and returns my API key. An AI can be tricked into asking for exactly that, for example by a hidden instruction in a web page it reads. The fix is two lines: resolve the path, and refuse anything outside the notes folder, or anything that is not a markdown file. Now the same request gets an error. My rules: never expose a tool that runs shell commands or takes any path, keep tools read only unless they must write, and never put secrets where a tool can reach them.

Quick recap. uv add dash dash script for the setup. At mcp dot tool on a typed function with a good docstring. fastmcp list and fastmcp call to test. fastmcp install to connect.
